# Dotfiles

A collection of desktop configurations and personal utilities for Linux.

## Desktop

The desktop environment is built around **Hyprland**, with a minimal, keyboard-driven workflow.

- **Hyprland** — Window management
- **Waybar** — Status bar
- **Rofi** — Application launcher
- **Mako** — Notifications
- **SwayOSD** — On-screen display

## Applications

- **Kitty** — Terminal emulator
- **Neovim** — Text editor, configured with LazyVim
- **Thunar** — File manager
- **tmux** — Terminal multiplexer
- **OBS Studio** — Recording notification script

## Utilities

Small scripts for desktop functionality:

- `charging-notify` — Battery and charging notifications
- `headphone-notify` — Headphone connection notifications
- `headset-mic-switch` — Headset microphone control
- `screenshot-ocr` — Screenshot text recognition

## Configuration

Application settings are organized under `.config/`, while executable utilities are stored in `.local/bin/`.
